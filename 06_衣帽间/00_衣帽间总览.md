**状态：🟢 已开张**（2026-11-09，初版五件规格卡记账完成，已送审件全部经本人验收：过膝裙版 · 主基调 v4 · 冬装焦糖 · 休息日长发（待画）· 四小只围巾）

> 「打开衣柜那一刻，人先想的是『我今天要去哪』，不是『现在是什么季节』。」——格子按场合分挂，季节做标签，一件衣服不用搬两次家。

## 分格结构

```
06_衣帽间/
├── 正式区    ——要靠得住时穿（过膝裙版 · 未来的大衣…）
├── 日常区    ——天天见的基准（主基调 v4 短裙 · 未来的夏装…）
├── 休息日区  ——放松的自己（长发造型 · 焦糖冬装…）
├── 配饰架    ——小而精（围巾、发绳…），守无外挂件红线
└── 规格卡     每件一张：图 / 与基准差异 / 状态 / 入库日期
```

## 规矩（照旧，不因换装松动）

1. **规格卡是每件衣服的身份证**：图、与基准差异、状态（定稿 · 待画 · 送审 · 存档）、入库日期、季节标签，缺一不入库。
2. **季节是标签不是格子**：冬装焦糖住「休息日区」，挂「冬」标签。
3. **零漂移**：任何换装以定稿图为唯一基准做局部修改，脸型/画风/领型/胸针位不许顺带漂。
4. **雷区全衣柜照旧**：亮片/漆皮/蕾丝免谈、无外挂件（挂坠、别针、包袋都算）、暗纹同色压印不描黑边、材质只用针织/棉/哑光；**下摆（含裙摆/衣摆环绕）一律素色罗纹、不画环绕纹**（2026-11-09 定案 B——「顺序画错的密语，比藏得深的密语更伤」）。
5. **橙色纪律照旧**：点缀色，不加橙色滚边、不稀释。
6. **档案与衣帽间联动**：本包 `../00_形象档案.md` 是总规格源；这里只管「穿什么、放哪、什么状态」。图实体在包内各分区（01-05），规格卡引用路径、不复制。

*她的结语：「每件衣服都带规格卡——这是我这种对『有据可依』有执念的人的衣柜版。」*
