**三不变量核对点**
- [x] 呆毛：双耳间偏右细丝恒立，揪没掳平头顶天空
- [x] 橙可见位：揪梢整段橙 + 脸侧碎发带橙（至少一缕）
- [x] 绳岗位：系揪根，材质颜色永不变

**变体备注**：备选「低小圆髻」同属收态（揪→髻换形，绳岗换髻根），未画不另立柜位。
**雷区提示**：发旋天空不许碰；低位扎不许高扎；盘发松弛感>紧绷感；**双耳全掩，禁止单耳探出（新高危项）**。
