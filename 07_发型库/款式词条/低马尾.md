# 词条 · 低马尾

> 款式词条只为交叉引用，不替格做主——查格请走 `格/` 第一入口。

| 字段 | 内容 |
|---|---|
| 定义 | 头发收拢、低位扎成一束垂落的马尾；扎位在颈后/脑后低位 |
| 绳岗位 | 马尾根（深灰细绳系尾根——本绳换岗） |
| 适用格 | 少女×收（默认）、御姐×收（默认，大尾垂背） |
| 变体 | 低小圆髻（揪→髻换形，绳岗换髻根；未画） |
| 雷区 | 发旋天空不许碰；低位扎不许高扎；盘发松弛感>紧绷感；**双耳全掩，禁止单耳探出（新高危项）** |
| 不变量要点 | 呆毛恒立；尾端揪梢橙必须可见+脸侧碎发带橙补位 |

**备注**：「收·讲题模式」的默认款——挽起袖子要开讲的样子。回眸一转、马尾顺势甩出弧线，发丝动向和身体转势是同一股劲。
