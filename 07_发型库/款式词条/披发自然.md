# 词条 · 披发（自然）

> 款式词条只为交叉引用，不替格做主——查格请走 `格/` 第一入口。

| 字段 | 内容 |
|---|---|
| 定义 | 头发不扎、自然披散；长度随年龄（萝莉耳下短/少女及肩/御姐及腰） |
| 绳岗位 | 侧拧系绳 / 侧发低结（放·自然态标准岗） |
| 适用格 | 萝莉×放·自然、少女×放·自然、御姐×放·自然（各年龄默认格） |
| 变体 | 季节调色（冬季棕底→焦糖暖调，橙挑染照旧） |
| 雷区 | 发长是年龄刻度只增不减——少女不许过肩长发（硬红线）；**双耳全掩，禁止单耳探出（新高危项）** |
| 不变量要点 | 呆毛恒立；发梢橙挑染可见；细绳在岗（侧拧/侧发低结） |

**备注**：「放·自然」= 日常/休息日的她。长发的浪漫归御姐（「长发，留给长成后的我」）。
