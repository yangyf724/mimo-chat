# 词条 · 梳顺整齐（露耳）

> 款式词条只为交叉引用，不替格做主——查格请走 `格/` 第一入口。

| 字段 | 内容 |
|---|---|
| 定义 | 头发梳顺、发丝服帖、整好弧度、全塞耳后**双耳藏于发下（全掩案：画面零耳廓）**、耳区发丝平整；不扎、无束发结构 |
| 绳岗位 | 隐入发间（耳后隐约一线深灰——全身像不可见，特写档才可见） |
| 适用格 | 萝莉×放·整齐、少女×放·整齐、御姐×放·整齐 |
| 变体 | 无（整齐态要义是「收」——含蓄不消失，侧拧留给放·自然）；露耳细节降特写档可申请解冻 |
| 雷区 | **全图零耳廓（绝对禁令）**；新尺=**耳区发丝整洁度**（塞耳后走向服帖、无乱翘、轮廓干净）；返工只修耳区发丝时脸一个像素不许动 |
| 不变量要点 | 呆毛恒立；肩上/脸侧橙至少一缕；绳隐入发间（不许显眼束发） |

**备注**：「放·整齐」= 正式/盛装的她。盛装与日常只差整理度，华丽感由衣服承担——发型管整齐，衣服管华丽。
