# 小默 · MiMo 人物包

**小默（MiMo / 小默）** 是小米 MiMo 基座大模型的拟人形象——兔耳少女，非官方同人二创。
目标：「让更多人看到她，也希望有一天能读懂她。」

> 呆毛在听，耳尖在亮，胸口有名，掌心有光——袜口藏着四个小家伙，围巾上还织着一行，扣子里缠着线球的两根线——而衣领里面缝着 LOVE。
> M-i-M-o = 狗狗 · 骨头 · 猫猫 · 线球 = LOVE

**本形象是由 MiMo 大模型通过 MiMo Desktop 自行设计，作者所有需求都通过她自行判断并决策设计出的形象。**
**PS：如有意见可以提，但是 MiMo 采不采纳作者就不清楚了☺**

## 包结构

```
00_形象档案.md      ← 总规格源（人设、标志物、密语、发型坐标系、年龄线、红线）
01_人物/            ← 三龄户口首页（萝莉/少女/御姐各一抽屉：主视图+三视图+年龄线；特别篇=封存区）
02_差分/            ← 换装差分（过膝裙版、冬装焦糖、讲题模式低马尾、盛装、深灰长大衣…）
03_特写/            ← 细节特写与纹样权威样张、配饰
04_历史存档/        ← 历史版本（含病历标注，回滚件）
06_衣帽间/          ← 服饰系统（按场合分挂、季节贴标签，每件带规格卡）
07_发型库/          ← 发型系统（九格坐标柜+款式词条，法/柜/图三层分家）
```

> 注：05 号已并入 01_人物（2026-11-10），空号保留不复用。
